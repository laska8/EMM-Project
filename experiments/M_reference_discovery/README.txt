M: activity-based reference subgroup discovery

The binary search returned 29 valid subgroups: nine with one condition and twenty with two. All 29 reciprocity coefficients were negative, ranging from -0.522 to -0.177, against a global reference of -0.2413. The highest-quality subgroup was Sent > 3 and Received > 3 (n = 5,056,348; return rate 75.78%; beta = -0.522; 95% CI [-0.537, -0.507]). Its AME was -7.55 percentage points.
